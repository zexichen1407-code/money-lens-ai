# 钱镜 AI（Money Lens AI）

一个个人现金流分析网页应用。用户可以上传银行、支付宝或微信流水，由云端在单次请求内完成解析，再由免费 AI 生成有数据依据的财务解读。

## 已实现

- 支持 CSV、XLSX 和文本型 PDF
- 兼容常见银行、支付宝和微信流水列名
- 自动识别收入、流出、转账和消费类别
- 计算净现金流、结余率、月度趋势及现金流评分
- 展示消费结构、最近交易和数据质量
- 使用 Gemini 3.5 Flash-Lite 免费 API 生成中文洞察与行动建议
- 用户无需注册、登录或提供任何 AI 平台账号
- AI 不可用时自动回退到本地规则分析
- 支持打印或保存分析报告为 PDF
- 适配桌面端和移动端

## 隐私边界

- 原始文件通过 HTTPS 上传到本站云端，仅在当前请求内解析，不写入数据库或对象存储。
- 不使用数据库、对象存储、localStorage 或 sessionStorage 保存流水。
- 仅匿名汇总金额、比例、固定消费类别和月度趋势会发送给 Google Gemini；姓名、账号、商户名称和单笔明细不会发送。
- 客户不需要登录或提供 API Key；站长需要在后端配置一次 GEMINI_API_KEY。
- Gemini 免费层可能使用输入和输出改进 Google 产品。

## 当前限制

- PDF 必须包含可选择的文本；扫描图片 PDF 暂不支持 OCR。
- 当前按人民币展示，不做多币种汇率换算。
- 不同银行导出格式可能需要补充列名适配。
- 免费 API 额度用尽或网络失败时，自动使用本地规则报告。
- 结果只反映上传区间内的现金流，不代表完整资产、负债、信用或投资能力。
- 分析仅供个人财务管理参考，不构成投资、信贷或税务建议。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
Copy-Item .env.example .env.local
# 编辑 .env.local，填写 GEMINI_API_KEY
npm run dev
```

打开终端显示的本地地址即可体验。没有流水文件时，可以点击“使用示例数据体验完整 AI 分析”。

## 验证

```bash
npm test
npm audit --omit=dev
```

测试会执行正式构建，并验证上传入口、隐私边界、产品元信息和分享预览图。
