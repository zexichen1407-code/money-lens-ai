# 钱镜 AI（Money Lens AI）

一个隐私优先的个人现金流分析网页应用。用户可以上传银行、支付宝或微信流水，在浏览器本地完成解析和计算，再由免费 AI 生成有数据依据的财务解读。

## 已实现

- 支持 CSV、XLSX 和文本型 PDF
- 兼容常见银行、支付宝和微信流水列名
- 自动识别收入、流出、转账和消费类别
- 计算净现金流、结余率、月度趋势及现金流评分
- 展示消费结构、最近交易和数据质量
- 使用浏览器本地 Qwen2.5 开源模型生成中文洞察与行动建议
- 用户无需注册、登录或提供任何 AI 平台账号
- AI 不可用时自动回退到本地规则分析
- 支持打印或保存分析报告为 PDF
- 适配桌面端和移动端

## 隐私边界

- 原始文件只在当前浏览器页面中读取，不上传到本站服务器。
- 不使用数据库、对象存储、localStorage 或 sessionStorage 保存流水。
- AI 模型直接在浏览器中运行，原始文件、商户明细和聚合指标都不会发送到本站服务器或第三方 AI 接口。
- 不需要用户登录，也不需要用户提供 API Key。
- 模型文件仅在首次使用时下载，之后由浏览器缓存。

## 当前限制

- PDF 必须包含可选择的文本；扫描图片 PDF 暂不支持 OCR。
- 当前按人民币展示，不做多币种汇率换算。
- 不同银行导出格式可能需要补充列名适配。
- 本地 AI 首次加载耗时取决于网络和设备性能；低性能设备会自动使用本地规则报告。
- 结果只反映上传区间内的现金流，不代表完整资产、负债、信用或投资能力。
- 分析仅供个人财务管理参考，不构成投资、信贷或税务建议。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可体验。没有流水文件时，可以点击“使用示例数据体验完整 AI 分析”。

## 验证

```bash
npm test
npm audit --omit=dev
```

测试会执行正式构建，并验证上传入口、隐私边界、产品元信息和分享预览图。
